Local RAG demo

A quick demo project where I set up a RAG with local LLMs, over the wiki of All the Numbers, a financial planning tool I'm building. This is a replay of what was run on my laptop.

How it works

Results

35 questions, 3 runs each. To pass, every refusal and every number must be correct.

I also tried hybrid search (keywords plus vectors). It found the right entry no more often, and refusals dropped (Gemma 12/18, Qwen 7/18), so search stays vector-only.

At larger scale

The app talks to the model through an OpenAI-compatible API, so the laptop server could be replaced by vLLM or llama.cpp on Kubernetes, or by a managed endpoint, without code changes. For users in many countries I'd expect to deploy the same stack per region to keep data in place, check that the embedding model and the eval cover every language in use, and fail over only to regions allowed to hold that data. Traffic across time zones also leaves little quiet time for batch jobs.
